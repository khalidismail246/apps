# Flowza

Flowza is a simple and lightweight personal finance tracking application built with Flutter.

The app helps users organize and manage personal financial records, including:

* Borrowed amounts
* Lent amounts
* Repayment dates
* Payment reminders
* Financial records and certificates

## Features

* Track borrowed and lent money
* Set repayment date reminders
* Manage financial records
* Store data locally using Hive
* Works completely offline
* Clean and easy-to-use interface

## Technologies Used

* Flutter
* Dart
* Hive Local Database
* Local Notifications
* Bloc State Management

## Privacy

Flowza stores all user data locally on the device. No financial information is transmitted to external servers.

## Getting Started

1. Clone the repository.
2. Run `flutter pub get`.
3. Run the application using:

```bash
flutter run
```
